# Contributing to Eyleme evaluations

Read the [canonical contribution workflow](https://github.com/eyleme-dev/devguide/blob/main/CONTRIBUTING.md), [local scope](README.md) and [contributor adapter](AGENTS.md). [Türkçe](CONTRIBUTING.tr.md).

Use the local feature, bug or architecture issue form and PR template. Run the exact commands in AGENTS.md. Independent maintainer review and any required repository-set update remain separate from local CI. First-party source and documentation are licensed under [Apache-2.0](LICENSE). Separately identified third-party material, model weights and datasets retain their own terms.
